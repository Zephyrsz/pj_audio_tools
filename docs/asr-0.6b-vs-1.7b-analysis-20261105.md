## 文本质量与对齐风险

- 有改善倾向的例子：裕楽町→有楽町，オルナイト日本→オールナイトニッポン，速い→早い。但1.7B同一输出也出现有楽庁、半 sleeve、半 sleeves、風等需要听校的写法。没有人工真值，不能计算CER/WER，也不能由15段或27段判断识别优劣。
- 两个模型都留下长句：0.6B最长23.76秒，1.7B最长25.08秒。max_sentence_seconds=30目前仅加long_sentence标记，不硬切句，修改该值不会自动恢复更多句子。
- 1.7B首词“東京”被对齐成1.760–1.760秒（零时长），导致第一段实际切点为1.660秒；0.6B首段从0秒切。VAD在同一输入上从1.216秒检测到人声，因此1.216–1.660秒存在裁掉语音的风险。是否切掉该词需试听源音频与两版000001.wav确认，不能把纯能量/VAD检测当作逐字真值。

## 优化顺序

1. 优先试听两版首段，复核零时长开头词与切片覆盖；这是独立于分句数量的对齐质量问题。
2. 将ASR识别和最终语义分句分开验收。当前可启用LLM选择现有对齐单位之间的边界；它不会自动修正字幕或补标点。
3. 如需有标点的字幕，新增受约束的标点恢复模块；只允许标点/空白变化，保存原稿与改动记录。文字纠错另行审计，避免LLM改写实际说法。
4. 规则/LLM结合上下文、语法和停顿分句，时长作为软约束；无需把27段当成目标条数，也不应为追求短音频把长句任意截断。
