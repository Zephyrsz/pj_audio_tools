# 语音片段抽取设计

第一版提供命令行与 Python 接口，底层使用系统 FFmpeg/ffprobe，无第三方 Python 运行时依赖，Python 3.10+。

- `extract_clip(input_path, start, end, output_path=None, *, overwrite=False) -> Path`。
- 时间为相对于音频开头的秒数、`MM:SS[.小数]` 或 `HH:MM:SS[.小数]`；区间是 `[start, end)`。必须满足 `0 <= start < end <= 音频时长`。
- 默认导出 `outputs/<原文件名>_<开始秒数>-<结束秒数>.wav`。显式路径支持 WAV、M4A、MP3、FLAC。WAV 使用 16 位 PCM，保持原采样率和声道数；有损格式重新编码，以保证定位准确，不使用直接复制压缩帧。
- 不改动原文件；默认拒绝覆盖已有输出。转换先写同目录临时文件，成功后发布，失败清理临时文件。
- 缺少依赖、文件不可读、非音频、非法时间、越界、输出格式不支持、转换失败时给出可理解的错误，命令行返回非零状态。
- 可复用模块独立于命令行，后续模块可以直接导入。

验证：真实 FFmpeg 集成测试检查样本位置、长度、采样率、声道及保护行为；用用户文件 `raw/20261028井上和.m4a` 截取前 100 秒，核查输出时长并完整解码。

取舍：Python + FFmpeg 兼顾后续扩展和低内存处理长音频；纯 shell 复用接口较弱；本地网页暂不在用户选择的范围内。
